

# NPTEL Quiz Game – One Health Exam Practice

This is a practice quiz web application designed to help students prepare for the **NPTEL One Health exam**.

## 🔗 Live Link

[https://nptel-quiz-game.vercel.app/](https://nptel-quiz-game.vercel.app/)

## Features

* Multiple-choice quiz questions
* Real-time score tracking
* Simple and responsive user interface
* Fixed header and footer layout

## Tech Stack

* React.js
* CSS

## How to Run

1. Clone the repository:
   `git clone https://github.com/your-username/nptel-quiz-game.git`

2. Navigate to the project folder:
   `cd nptel-quiz-game`

3. Install dependencies:
   `npm install`

4. Start the development server:
   `npm start`
